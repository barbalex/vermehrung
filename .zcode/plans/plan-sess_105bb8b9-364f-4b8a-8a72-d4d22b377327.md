Object lists at object URLs (apf2-style drill-down), gated by `breadcrumbsEnabled`. With the flag on, an object URL like `/Vermehrung/Arten/{id}` renders a list of the object itself + its child tables (tree order); the object's form moves to `/Vermehrung/Arten/{id}/Art`. Tree clicks and newly created datasets open the form directly; leaf objects (Zählung, Teilkultur, Lieferung, Bedarf) render their form directly (no one-row list); no counts on rows for now. Flag off = exactly today's behavior.

## Key insight
The existing URL matcher (`activeFormFromActiveNodeArray`) already returns the object-form key for every object URL, and the suffix can be stripped from `activeNodeArray` exactly like the existing `/histories/{rev}` suffix — so the 690-line matcher needs **zero changes**, and tree highlighting, id atoms and list scoping keep working positionally.

## 1. Suffix mechanism (utils + store)
- New `src/utils/singularOfFolder.ts`: folder → singular map (`'Arten'→'Art'`, `'Herkuenfte'→'Herkunft'`, `'An-Lieferungen'→'Lieferung'`, `'Bedarf'→'Bedarf'`, … all 13 folders).
- New `src/utils/splitObjectNameFromActiveNodeArray.ts` (mirrors the histories splitter): strip the trailing segment only if it equals `singularOfFolder(url[len-3])` and the segment before it is a uuid. This naturally disambiguates `'Bedarf'`-as-folder (`Kulturen/{k}/Bedarf`, owner folder `Kulturen` → singular `Kultur` ≠ `Bedarf`) from `'Bedarf'`-as-suffix (`…/Bedarf/{id}/Bedarf`).
- `src/store/index.ts`: new non-persisted `activeObjectNameAtom`. In `setActiveNodeArray`, when `breadcrumbsEnabled`: strip the suffix from the value before setting `activeNodeArrayAtom`/`addOpenNode`, set `activeObjectNameAtom`, but navigate to the full URL (with suffix). Flag off: untouched. `NavigationSyncController` needs no change — it funnels through `setActiveNodeArray`, so direct URL loads work too.

## 2. Breadcrumbs
- Append the object name as the final plain-text crumb when set (the object's own row crumb automatically becomes a link to the list).
- Extract RowCrumb's label subscription into a shared `useRowLabel(table, id, parentFolder)` hook (used by RowCrumb and by the new list header).

## 3. Generic ObjectList + Data wiring
- New `src/components/Data/ObjectList.tsx` (+ css module styled like the existing folder lists): header shows the object's own reactive label; rows navigate via `setActiveNodeArray` — self row → `[...aNA, singular]`, folder rows → `[...aNA, folder]` (existing folder lists render there).
- New children config per entity × context, mirroring the tree order exactly:
  - art → Herkünfte, Sammlungen, Kulturen
  - herkunft → Sammlungen (+ Kulturen only when under `Arten`)
  - sammlung → Herkünfte + Aus-Lieferungen (top-level `Sammlungen`), else Aus-Lieferungen
  - garten → Kulturen; person → Sammlungen, Gärten, Lieferungen
  - kultur → Teilkulturen (only if reactive `kultur_option.tk`), Zählungen, An-Lieferungen, Aus-Lieferungen, Bedarf
  - sammel_lieferung → Lieferungen
  - teilkultur/zaehlung/lieferung/bedarf → none (form renders directly, cases untouched)
- `src/components/Data/index.tsx`: for the 7 branching entities wrap the case: `breadcrumbsEnabled && !objectName` → `<ObjectList/>`, else the existing form component. Leaf-entity cases unchanged.

## 4. Direct-to-form paths
- `src/components/Tree/toggleNode.ts`: flag on + `nodeType === 'table'` + `singularOfFolder(node.url.at(-2))` exists → navigate to `[...node.url, singular]` (tree clicks keep today's efficiency).
- `src/modules/insertRev.ts`: in the central navigate block, append the singular when the map has one, so newly created datasets open on their form.
